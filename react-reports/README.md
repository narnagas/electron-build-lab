# React reporting POC

Planned standalone React application for learning components, state, API integration, charts, and PDF generation.

## Folders

- `src/components/`: reusable controls and layout components.
- `src/pages/`: reporting screens.
- `src/services/`: client for the reporting microservice.
- `src/reports/`: PDF templates and report-specific presentation.
- `src/charts/`: chart components.
- `src/styles/`: shared styling.
- `public/`: static assets.

First example: Daily Orders filters, results table, orders-by-day chart, and PDF preview/download. Begin with clearly identified sample data, then connect to the reporting service. Electron will open the reporting app independently of Angular.

This is a folder scaffold; no React application or dependencies have been installed yet.
